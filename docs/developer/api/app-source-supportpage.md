# 手机应用上的用户支持

::: warning 适配性警告
本页面所提供的服务仅限 Vilinko Studio 内部开发使用，若您不是 VIS 团队成员，此页面所提供的功能对您的开发来说是没有作用的。
:::

## 嵌入服务链接

::: tip 提示
因为有 `support.vilinko.com` 对用户提供主要服务，所以本文章不提供手机版本的服务中心首页嵌入功能。
:::

### 文档中心

尝试在应用加入显示在线 URL 的页面，然后使用以下链接，注意不要丢失查询参数。

```txt
https://yuyupage.vilinko.com/api/app-source-support.html?page=docs&back=false
```

### 服务状态检测

此页面将在用户点击 “检测” 后检查当前应用到服务地址的网络可达性。目前仅提供到主站、文档和服务支持页面的测试。        
尝试在应用加入显示在线 URL 的页面，然后使用以下链接，注意不要丢失查询参数。

```txt
https://yuyupage.vilinko.com/api/app-source-support.html?page=status&back=false
```

### 反馈
