# User Support for Mobile Applications

::: warning Compatibility Warning
The services provided on this page are exclusively for internal development use within Vilinko Studio. If you are not a member of the VIS team, the features offered on this page will be of no use to your development.
:::

## Embed Service Link

::: tip Tip
Since `support.vilinko.com` provides the primary service to users, this article does not offer the embedded function for the mobile version of the service center homepage.
:::

### Documentation Center

Try adding a page to the application that displays the online URL, then use the following link, making sure not to lose the query parameters.

```txt
https://yuyupage.vilinko.com/api/app-source-support.html?page=docs&back=false
```

### Service Status Monitoring

This page will check the network accessibility of the service address currently applied after the user clicks "Detect." Currently, only tests to the main site, documentation, and service support pages are available.
Try adding a page to the application that displays the online URL, then use the following link, making sure not to lose the query parameters.

```txt
https://yuyupage.vilinko.com/api/app-source-support.html?page=status&back=false
```
